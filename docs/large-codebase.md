# 単一実装のサンプルと、大規模な未改変OSS

## 改善候補を同梱しない

GameLabとRaidLabの改善候補のコードを現行ツリーから削除しました。対象処理は1実装です。RaidLabはRaidAnalyzer、GameLabはCountOwned / Build / SumBucketsという名前に整理しました。旧比較モード、改善版を選ぶプリセット、答えを説明するガイド、教材用NoInlining、未実行の静的検知専用例も外しています。

仕様と既存の機能を確認するテストは残します。別実装との一致を期待値にはせず、固定の期待値・境界値・不変条件を確認します。RaidLabは46ケース（うち生成データの不変条件27）、GameLabは簡易確認8件とxUnit22ケースを定義しています。ケース定義と実行成功は別です。

ベンチマークは現在の実装1つを測ります。変更前の結果を保存し、外部エージェント自身が変更した後に同条件で再測定してください。以前のチェック記録やGit履歴は消していません。過去のソースや結果を最新として扱わないでください。自作教材という出自は変わらないため、未加工の実コードに対する評価には以下のOSSを使います。

## 大規模な対象: ILSpy

公式 `icsharpcode/ILSpy` の **v10.0 / 5deb6fb4258a09ba0ff5f63fa6180b1f8d6fb6ad** を固定した評価用取得レシピです。最新ブランチを追いかけず、同じソースから繰り返し調査するための版です。旧版を本番利用する推奨ではありません。上流のMITライセンス・テスト・通常のコメントを保持します。問題箇所の印や改善答案は追加しません。

.NETの逆コンパイラーの実装で、構文木、型システム、IL/制御フロー、メタデータ、プロジェクト出力、コマンドラインなどを含みます。全体ソースを取得します。初期の解析用ソリューションは **Decompiler / ILSpyX / ILSpyCmd の3プロジェクト** で、上流ソースの外に作ります。元の.csproj、global.json、C#、テストは書き換えません。上流の全体構成ILSpy.slnもそのまま残ります。

全体構成にはWindows UI、旧.NET向けのテスト等があり、追加の開発環境やサブモジュールが必要になる場合があります。初期BATではそれらの一括ビルドや上流テストを自動実行せず、CLIと依存ライブラリを対象にします。Decompilerはnetstandard2.0、ILSpyX/CLIはnet10.0です。甜花ちゃんの既存DLL自動検出・PDB対応の制約は残るため、エンジンの全メソッドについてJIT取得まで自動対応したとはしていません。

取得後の `size-report.json` に、追跡C#のファイル数・物理行数・csproj数、Decompiler本体だけの件数、変更有無を保存します。全体にはテストや生成済みソースも含みます。行数を水増しするコードは追加しません。この作業環境ではダウンロード未実行なので、未計測の固定LOC数を掲げていません。

## 操作

1. 甜花ちゃんと外部MCPアダプターを終了し、本体で `git pull --ff-only`。
2. 本体の **run-large-oss.bat → 1 → Y**。公式ソースを取得し、コミットを照合します。取得だけでMSBuildやアプリを実行しません。
3. 同じBATの **2 → Y**。NuGet復元とCLIのReleaseビルド。必要なのはGit for Windowsと.NET 10 SDKです。上流のビルドがPowerShellを使います。SDKは自動インストールしません。
4. `start.bat`で甜花ちゃんを起動し、Ctrl+F5。「プロジェクト調査 → 準備 → 付属サンプル → ILSpy → 選んだサンプルを使う → 読み込む」。通常のDLL/プロジェクトID操作を使います。
5. 外部エージェントも `tenka_sample(sample="ilspy")` で場所を取得できます。未準備の場合はBATを案内するだけで、ダウンロードを勝手に始めません。

BATの3はビルド済みCLIの`--help`による起動確認で、テストや実際の性能計測ではありません。4は規模と状態の表示です。通常の既定起動だけでは特定メソッドに到達しません。実行計測には自分が扱う権限のある入力DLLと再現可能なワークロードを別途用意してください。

取得先は本体の `samples/External/ILSpy-10.0/source`、解析用ソリューションは同じ親フォルダーの `ILSpy.Analysis.slnx` です。本体の許可範囲内で選択し、許可範囲は勝手に広げません。外部フォルダーは甜花ちゃんのGit管理から除外しています。

## 再実行時の保護

既存チェックアウトの取得元とHEADが一致しない場合は停止し、reset/clean/pullによる上書きはしません。ローカル編集がある場合も残し、ビルド・実行前に確認します。初回は一時ディレクトリへ取得して照合してから移動します。失敗した一時ディレクトリも自動削除しません。

取得はコミット履歴を含みます。上流のバージョン生成が履歴を参照するため、浅い取得ではありません。上流のビルドがバージョン情報などを生成することはありますが、この取得レシピによるソースパッチはありません。取得/ビルドはネット接続や現在のユーザー権限を使用します。同一OSユーザーによる悪意ある変更を防ぐサンドボックスではありません。

ソリューション全体が巨大な場合は索引・レポートの上限や時間制限に達する場合があります。未返却部分を確認済みにせず、プロジェクト/型ごとに範囲を分け、pendingのキューと確認状況を使用してください。GitHub CIは停止を維持し、Dockerを導入しません。

## 検証

この変更で実行したのは **Node.js 169テスト**、模擬APIを使うChromiumで **RaidLab 30項目＋ILSpy選択21項目**、Pythonによる **構成・独立した固定期待値の検査60項目** です。ブラウザーは新HTML/JSと共通CSSを使用し、既存styles.css/app.jsを省略した分離検査です。C#の実行ではありません。

この作業環境は.NET SDKとPowerShellがなく、外部GitHub/dot.netへの名前解決も失敗しています。**C#ビルド、RaidLab/GameLab仕様テストの実行、新規カタログ5ケースのC#テスト、Windows BAT、実際のILSpy取得・ビルド・実測は未実行**です。固定SHAと元プロジェクト構成はGitHubの一次資料で確認しました。CIを再開しての検証は行いません。
