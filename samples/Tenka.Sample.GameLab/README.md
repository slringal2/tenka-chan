# GameLab — 小規模な実行サンプル

所持品検索、ログ生成、バケット集計、共有カウンターを含む.NET 8のアプリです。
各処理は1つの実装だけを収録し、別の改善版や比較モードは同梱しません。

run-lab.batの1=参考計測、2=仕様の簡易確認、3=xUnit、4=現在の所持品検索のBenchmarkDotNet計測です。
.NET 8ランタイムと.NET 8以上のSDKを使用します。初回にNuGet復元が必要になる場合があります。

起動引数は`--scenario inventory|report|damage|contention`、`--size 1..3000`、`--iterations 1..100`または`--seconds 1..20`です。
既定は所持品検索のみです。別のシナリオのJITを調べるときは、そのシナリオで起動してください。
`--verify`は固定期待値8件の簡易確認、xUnitは固定値・境界値・不正入力等を追加で確認します。

所持品検索は負の所持IDを無視し、要求の重複は個別に数えます。ログはInvariantCultureで各IDの後ろにカンマを付けます。
バケット集計は非負の入力と正の2のべき乗のバケット数を受け付け、各値をバケットに割り当てた添字の合計を返します。
共有カウンターは4ワーカーが各指定回数増加し、更新が失われないことを検査します。

自作教材という出自は変わりません。未加工の大規模実コードの評価には、run-large-oss.batで取得するILSpyを使ってください。
元の仕様テストを消す必要はありません。仕様を根拠に変更前後の正しさを調べ、速度は同じ条件で実測してください。
旧版のメソッド名・比較用起動引数は廃止しました。更新後にビルドし、過去のJIT/測定結果と混同しないでください。
