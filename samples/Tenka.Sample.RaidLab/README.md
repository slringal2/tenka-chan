# RaidLab — 戦闘ログ集計

Domain / Infrastructure / Application / Host / Tests / Benchmarksの6プロジェクトです。
JSON読込、イベント検証、プレイヤー・ギルド集計、順位付け、レポート生成を扱います。
アプリケーションに収録する実装は各処理1つです。別の改善版は同梱しません。

## 実行

本体のrun-raid-lab.bat、またはこのフォルダーのrun-lab.batを起動します。
1=初回準備、2=仕様テスト、3=参考計測、4=4秒実行、5=4並列バッチ、6=xUnit、7=集計単体計測、8=パイプライン計測、9=場所表示です。
.NET 8ランタイムと.NET 8以上のSDKが必要です。初回復元はネット接続を使う場合があります。

甜花ちゃんでは「プロジェクト調査 → 準備 → RaidLab → 読み込む」。起動対象はTenka.Sample.RaidLab.Hostです。
コードを変えた後も同じ仕様を守る必要があります。CONTRACT.mdを根拠にしてテストしてください。
固定期待値・エラー・キャンセル・生成データの不変条件を含む46ケースをHostとxUnitから共用します。
不変条件の検査は別実装との比較ではなく、正しさの完全証明でもありません。

## 計測

`--scope analyzer|pipeline|batch`、`--players`、`--events`、`--iterations`、`--seconds`、`--concurrency`で入力条件を指定します。
旧来の比較モードは廃止しました。実行入口は1つです。BenchmarkDotNetも現在の実装だけを計測します。
変更前の結果を保存し、外部エージェントが変更した後に同条件で測り直してください。
固定時間の計測は処理回数が異なるため、総割り当てを1回あたりの改善率にしてはいけません。

本体処理はメモリ内のデータを使用します。ビルド・計測ツールの書き込みや通信は別です。
このコードは以前に教材として作成したものです。改善版を除いても、未加工の実プロジェクトを評価したことにはなりません。
大規模な実コードには、本体のrun-large-oss.batで取得するILSpyを使用してください。

旧版のソース名・比較モードは変更しています。旧DLLや古い取得結果は最新実装として扱わず、更新後にビルド・再読み込みしてください。
C#ビルド・Windows実行の検証範囲はdocs/large-codebase.mdを参照してください。
